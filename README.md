# AI Cover Letter Generator

A full-stack AI-powered web application that generates professional cover letters using AI.

## Features
- AI-generated cover letters
- Secure backend API handling
- Copy functionality
- Responsive UI
- Loading & error states

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenRouter API
