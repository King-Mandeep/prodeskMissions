A modern multi-step registration form built with React, Tailwind CSS, and Vite.

This project demonstrates state lifting, conditional rendering, real-time validation, password visibility toggles, and responsive UI design.

## ✅ Phase 1 Features

* Multi-step registration form

* Shared parent state management
* Conditional rendering
* Review & Submit step
* Success screen after submission

* Dynamic error messages

# 📋 Validation Rules

## Step 1

* First Name → minimum 2 characters
* Last Name → minimum 2 characters
* Date of Birth → required

## Step 2

* Email → valid email format
* Password → minimum 8 characters
* Confirm Password → must match password
